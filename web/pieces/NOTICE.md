# Vector chess pieces

I use twelve SVG pieces by Colin M. L. Burnett (Cburnett) and the contributors recorded on the Wikimedia Commons file pages. I obtained them from [Cburnett's gallery](https://en.wikipedia.org/wiki/User:Cburnett/GFDL_images/Chess) and its corresponding Commons files on 2026-10-01.

I use the BSD license option offered on those pages. Source pages, download URLs and file hashes are recorded in [sources.json](sources.json). I added a `viewBox` where missing to allow scaling; the paths and colors are unchanged. The following notice applies to the artwork.
